Custom Music
============

This is a ready-to-install Project Avalanche music mod with three song
placeholders.

1. Replace music/song_01.wav, music/song_02.wav, and music/song_03.wav with
   your own music.
2. Edit music/playlist.toml with the artist, title, and playlist settings.
3. Copy this folder into the game's mods folder, or create a zip whose root
   contains resource.toml, music/, and this README, then install the zip from
   the launcher's Mods page.

Supported audio formats are OGG Vorbis, FLAC, and WAV. Only distribute music
you created or have permission to redistribute.

The included song_01.wav is a one-second silent placeholder.
